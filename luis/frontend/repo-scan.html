Scan a repo's real dependencies.

Paste a package-lock.json or requirements.txt. We find every known CVE affecting your exact dependency versions (via OSV.dev) and rank the ones that aren't already on the CISA KEV list with the same model behind the Top 500 — not raw CVSS.

We only read the lockfile you give us — package and version strings. Never your source code, and nothing is stored after the scan.

Public repos only. We clone it (depth 1, no credentials), find every package-lock.json/requirements.txt in it (up to 8), scan each, merge the results — then delete the clone. We never keep or send the rest of the code anywhere.
